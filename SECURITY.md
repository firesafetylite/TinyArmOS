# Security Policy

## Supported versions

Security fixes are provided for the latest published TinyGPT release. The project is pre-1.0 and older releases may not receive fixes.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting at:

https://github.com/firesafetylite/TinyGPT/security/advisories/new

Include the affected version, reproduction steps, impact, and any suggested mitigation. Avoid sharing sensitive details publicly until a fix or coordinated disclosure is ready. You may follow up in the private advisory if additional information becomes available.
